# The Agent Class

Learn AI agents by watching them get built. Real code, real bugs, real fixes.

Every build in a [YouTube Short](https://www.youtube.com/@theagentclass) lives here, so you can
run it yourself instead of just watching it.

- **One repo per build.** Small, runnable, with a README that says what the Short showed.
- **Agents and automation**: LangGraph, tool calling, evals, and which AI tool to use for which job.
- **Found a bug?** Open an issue. The best ones become the next Short.
